# Mxrckyyy — Web Developer Portfolio

Job-focused developer portfolio for **John Marc Comeros**, an aspiring junior web developer based in Cebu, Philippines.

## Stack

- React 19 + Vite 7
- lucide-react (icons)
- framer-motion (micro-animations, Phase 7)

## Getting started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run preview  # preview production build
```

## Project structure

```
src/
├── components/
│   ├── layout/      # Navbar, Footer
│   ├── sections/    # Hero, About, Skills, Projects, Resume, Contact
│   └── ui/          # Button, SectionHeading, ProjectCard, SocialLinks
├── data/            # projects.js, skills.js, socialLinks.js
├── App.jsx
├── main.jsx
└── index.css        # dark-mode design tokens
```

## Rules

1. Strict truthfulness — no invented experience, metrics, or skill percentages.
2. Project-centric — real GitHub/academic projects only.
3. Modular architecture — reusable components, data-driven content.
4. Dark-first, minimal, responsive down to 320px.

See `PORTFOLIO_CONTEXT.txt` for the full blueprint and 10-phase build plan.
